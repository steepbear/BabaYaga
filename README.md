# «Баба Яга против!» — сайт-прототип v2

Создан как первый прототип лендинга настольной игры и библиотеки вопросов. Сайт использует пять оригинальных изображений, предоставленных автором: игровое поле без дорожек и иллюстрации Бабы Яги, Змея Горыныча, Лешего и Кота Баюна. Старое изображение поля с вымышленными дорожками и прежний фоновый лес удалены.

## Что изменилось в V2

- На главной, в правилах и блоке покупки показано именно текущее поле без дорожек.
- Карточки четырёх злодеев оформлены с предоставленными изображениями.
- Тексты уточнены: дорожки на поле ещё не нанесены.
- Иллюстрации оптимизированы в WebP для быстрой загрузки.
- Сохранён генератор вопросов и три категории библиотеки: основная, общая преподавательская и личная.

## Как открыть

Распакуйте архив и откройте `index.html` двойным щелчком. Все изображения, стили и сценарии лежат в архиве, интернет для просмотра не нужен. Библиотека открывается со страницы `library.html`. Для просмотра введите `DEMO` или выберите «Посмотреть демоверсию».

## Что уже работает

- Адаптивная главная с объяснением игры и разделом для будущих ссылок на Ozon/Wildberries.
- Краткий обзор правил `rules.html` (не окончательная редакция печатного документа).
- Выбор 1–4 класса, одного из 4 предметов/злодеев и источника вопросов.
- Случайная выборка по разным темам без дублирования одного вопроса внутри набора.
- Разделение вопросов по сложности (3 демонстрационных уровня; значения следует согласовать с окончательными правилами).
- Печать: браузерное «Печать / PDF», при печати ответы идут на отдельной странице.
- Добавление и удаление своих вопросов в двух категориях: «личные» и «вопросы преподавателей».
- Хранение добавленных вопросов **локально в браузере** (localStorage). Эти данные доступны только этому браузеру/профилю устройства, а не конкретному человеку. Не стоит использовать для реальных персональных или конфиденциальных материалов.

## Чего нет — принципиально

**Не готово к коммерческому размещению в качестве закрытой библиотеки.**

- `DEMO` — *не настоящий код доступа*: проверка выполняется на клиенте. Все тестовые вопросы статически включены в JS и доступны посетителю.
- Нет серверной авторизации и учётных записей преподавателей.
- Нет настоящей защищённой приватной базы: «личные» данные хранятся в localStorage. Любой человек на этом же устройстве и в том же браузерном профиле может их увидеть.
- Нет публикации вопросов от одного преподавателя для других. Вопросы «для общей библиотеки» в демо тоже хранятся только локально.
- Нет панели владельца сайта для добавления и редактирования основной базы.
- Нет карточек товаров или реальных ссылок маркетплейсов.
- Демонстрационные вопросы не проходили педагогическую редактуру.

## Как превратить в рабочий сервис

1. Разместить статические файлы на хостинге.
2. Добавить сервер и БД (например, PHP + MySQL). Структура: `questions(id, owner_id, class, subject, topic, level, question, answer, visibility, status)` и `teachers(id, username, password_hash)`; основной код активации следует проверять только на сервере.
3. Разделить **доступ к библиотеке** по постоянному коду с игрового поля и **идентификацию преподавателя** по отдельным логину/паролю (можно без email). Без личной учётной записи сервер не сможет отличать одного преподавателя от другого.
4. Сервер всегда ограничивает выборку личных вопросов текущим `owner_id`; пользовательские общие публикуются в отдельном каталоге, основная редакционная библиотека — в своём.
5. Для общей библиотеки понадобится обработка жалоб/удаление нарушающего контента и правила использования.
6. Настроить резервное копирование базы. Общий пароль на поле может быть передан другим людям — как коммерческое условие этот риск нужно учесть заранее.
7. Проверить соответствие требованиям защиты персональных данных при хранении учётных записей, особенно если сервис ориентирован на школы.

## Правка содержания

- Тексты главной: `index.html`.
- Краткие правила: `rules.html`.
- Демонстрационные вопросы: `js/questions.js`.
- Логика библиотеки: `js/library.js`.
- Оформление: `css/style.css`.
- Изображения: `assets/`.

Не размещайте реальные пароли и секреты в JavaScript и HTML на открытом сайте.

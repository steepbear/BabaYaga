# «Баба Яга против!» — школьный образовательный проект

Сайт школьного проекта настольной игры, сочетающей повторение учебного материала с приключением и командным взаимодействием.

## Страницы
- `index.html` — идея проекта, персонажи, механика, учебная библиотека и макеты игрового поля.
- `rules.html` — правила игры.
- `library.html` — действующая редакционная библиотека вопросов по коду с игрового поля.

## Библиотека
- Supabase PostgreSQL: 1200 редакционных вопросов для 2-го класса по четырём предметам.
- Сложность вопросов зависит от кубика: 1–2, 3–4 и 5–6.
- Без регистрации: серверная проверка кода и выдача случайных вопросов через `get_game_questions`.
- Печать заданий и ответов, просмотр ответа на сайте.
- Временный тестовый код: `DEMO2026`. В готовых игровых материалах нужно использовать окончательный код.
- Вопросы других классов и личные кабинеты преподавателей находятся в планах развития проекта.

## Технологии
HTML, CSS, JavaScript; GitHub Pages для сайта и Supabase для библиотеки. Секретные ключи не публикуются.

## Статус
Сайт представляет школьный образовательный проект без коммерческих разделов и рекламы магазинов.

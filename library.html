Ответы для преподавателя

    Для печати в PDF выберите «Сохранить как PDF» в окне печати браузера.

    Добавить вопрос

    Вы можете оставить вопрос личным или отметить его для общей библиотеки преподавателей.

    Как это будет работать после запуска: личные вопросы будут доступны только в вашем кабинете. Общие материалы будут опубликованы отдельно от основной базы и без предварительной редакционной проверки. Сейчас оба варианта хранятся только в этом браузере: на сайт они не публикуются.
    Кто сможет пользоваться этим вопросом?

    В этой версии данные остаются на вашем устройстве.

    Мои вопросы

    Ваши собственные материалы, добавленные в этом браузере.

    Приватность демоверсии: никто не получает эти вопросы через сайт, но они доступны любому, кто использует этот же браузер и профиль устройства. Для настоящего личного кабинета понадобится отдельная учётная запись преподавателя на сервере.

    Можно добавлять вопросы для любого класса и предмета.
